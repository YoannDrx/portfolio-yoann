# Portfolio Yoann — design system

Le portfolio s'adresse aux recruteurs et responsables produit. Son positionnement est : **« Développeur produit React / Next.js — du prototype au produit fiable »**. Il montre les décisions, les contraintes, la qualité et la livraison ; il n'expose aucun dépôt client privé.

- Blanc chaud `#FAF9F6`
- Encre `#111827`
- Ultramarine `#2457E6`
- Menthe `#22A06B`
- Gris bleuté `#64748B`
- Titres Space Grotesk, texte Inter, preuves techniques Geist Mono

La vue web éditoriale est l'entrée principale. Le simulateur iPhone est un détail activable. Les études de cas principales sont Moodday, Jobio et MyCryptoPilot ; EggscuseMe, Hyrun, ReactMentor et French Data Generator sont secondaires. Tout chiffre doit être vérifiable et toute étude de cas explicite ses limites.
